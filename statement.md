# Project Statement

## Problem Statement
Images captured by cameras or obtained from real-world environments can contain unwanted noise. Noise reduces image quality and can affect later computer vision tasks. A simple tool is required to demonstrate how classical filtering methods can reduce noise and restore an image.

## Scope
The project focuses on basic image denoising using Gaussian, Median, and Bilateral filters. It also provides quantitative evaluation using MSE and PSNR.

## Target Users
- Computer Vision students
- Beginners learning image processing
- Users who want to demonstrate basic image restoration

## Objectives
1. Accept an image as input.
2. Generate controlled noisy versions of the image.
3. Apply classical filtering techniques.
4. Compare original, noisy, and restored images.
5. Measure restoration quality using MSE and PSNR.

## High-Level Features
- Image upload
- Gaussian noise
- Salt-and-pepper noise
- Gaussian filtering
- Median filtering
- Bilateral filtering
- MSE and PSNR
- Restored image download
